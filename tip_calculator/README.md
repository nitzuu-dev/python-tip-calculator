# 💸 Tip Calculator

This is a beginner-friendly Python script that calculates how much to tip based on a user’s bill and tip percentage.

## 🧮 How It Works

The script:
- Asks for the total bill amount
- Asks for the desired tip percentage
- Calculates the tip
- Calculates the total amount to pay (bill + tip)
- Displays both the tip and the total amount

## 📌 Example
Enter the total bill: 100
Enter tip percentage: 15
You should tip: 15.0
Total amount to pay: 115.0

## 🚀 How to Run

Make sure you have Python installed. Then:

1. Save the script as `tip_calculator.py`
2. Run it using:

```bash
python tip_calculator.py
